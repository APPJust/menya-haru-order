# 麵屋小晴｜拉麵線上訂餐

依兩張課程規格圖製作的手機友善訂餐網站。前台與店家後台頁尾署名均為「資通系 李振偉老師」。

## 點餐功能

- 豚骨拉麵、醬油拉麵、沾麵三個分區，各有 3 道餐點；店名標誌與每碗拉麵插畫皆由 SVG 繪製。
- 每道餐點有名稱、價格與說明。點餐時可選麵條硬度、加購溏心蛋或叉燒、調整數量。
- 購物車會保存在目前瀏覽器，重新整理後仍在；可以增加、減少或刪除品項。
- 結帳驗證姓名、09 開頭手機號碼與取餐時間；送單後顯示訂單編號，付款方式為到店付款，不串接金流。
- 後台示範登入：帳號 `just`、密碼 `just`。可瀏覽訂單、篩選狀態、修改訂單狀態，並查看訂單數、訂單總額及已完成營業額。

## GitHub Pages 部署

這是純 HTML、CSS、JavaScript 靜態網站，無需建置指令。將此資料夾內容放在 GitHub repository 根目錄，於 **Settings → Pages** 選擇 **Deploy from a branch**、`main`、`/(root)` 即可。

GitHub Pages 不提供後端資料庫或伺服器驗證，因此目前購物車與訂單都存放在使用者目前的瀏覽器；不同顧客或裝置的資料不會同步。後台的 `just / just` 是課堂展示登入，不適合保護正式營運資料。若要多人共用正式訂單，需再接上獨立的後端與資料庫。

## 本機預覽

可直接開啟 `index.html`，或在此資料夾執行 `python -m http.server 8000`，再瀏覽 `http://localhost:8000`。
