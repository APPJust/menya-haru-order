SYSTEM · TECHNOLOGY · DATA

這個網站如何運作？

從瀏覽器畫面、點餐流程到部署方式，一次看懂麵屋小晴的系統架構。

純前端
靜態網站
網站平台GitHub Pages

由 GitHub repository 的 main 分支根目錄發布，直接提供靜態網頁檔案，顧客使用瀏覽器即可開啟。

使用技術HTML + CSS + 原生 JavaScript

不依賴前端框架、套件安裝或打包建置；餐點插畫與店標以程式碼內的 SVG 向量圖繪製。

目前資料位置顧客自己的瀏覽器

購物車與訂單存於 localStorage；後台登入狀態存於 sessionStorage，不連接雲端資料庫。

A

前台點餐流程

JavaScript 讀取 9 道餐點與 3 個分類，產生餐點卡片及 SVG 拉麵圖。顧客選擇麵條硬度、加購配料和數量後，客製品項寫入 localStorage 購物車；結帳會驗證姓名、手機與取餐時間，再建立訂單、清空購物車並顯示訂單編號。

B

店家後台流程

前台與後台是同一個網站中的兩個畫面，網址雜湊切換到 #admin 即進入後台。示範帳號 just／密碼 just 由瀏覽器端比對；後台讀取同一瀏覽器的訂單資料，計算訂單數與金額，並可篩選及修改製作中、可取餐、已完成狀態。

C

部署與資料界線

GitHub Pages 負責發布檔案，不執行伺服器程式，也沒有資料庫、跨裝置同步或線上付款。localStorage 依網站來源和瀏覽器分開，因此顧客在自己手機送出的訂單不會出現在店家的另一台裝置。登入帳密在前端程式中，僅供課堂示範，不具正式安全性。
